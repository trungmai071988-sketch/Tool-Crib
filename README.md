# Trung Mai's Territory — EDP & Price Finder

A self-contained cutting-tool sourcing and reference tool covering Harvey Tool, MA Ford, Helical Solutions, Precision Twist Drill (Dormer/PTD), and Internal Tool Inc. (ITC).

## Live App

Once GitHub Pages is enabled (see below), this app will be live at:

```
https://<your-username>.github.io/<repo-name>/
```

## How it works

Everything — UI, styling, and the full tool database — is bundled into a single `index.html` file. No build step, no server, no dependencies. Data is stored in the browser via `localStorage`, so entries you add or import persist locally in your browser only.

## Deploying / Updating

1. Push changes to the `main` branch.
2. GitHub Pages (Settings → Pages) will automatically redeploy `index.html`.

## Local use

You can also just double-click `index.html` to open it directly in any browser — no hosting required.
