One tool per line, fields separated by commas:
brand, type, diameter, edp, price, loc, specs, notes
(loc = length of cut in inches. loc, specs, and notes are optional — leave blank if unknown)

Example:
Guhring, Carbide Drill, 0.5, GU-4021, 38.50, 1.0, 2FL AlTiN, coolant-through
Maford, Carbide Drill, 0.5, MF-1187, 41.20, 1.25, 2FL,
Fastest way to load a whole brand catalog: export it (or retype it) as a CSV with these columns:
brand, type, diameter, edp, price, loc, specs, notes
(loc = length of cut in inches, optional)
Then import below. You can do this once per brand catalog.
The catalog lives in tools.json, right next to this page on GitHub. Tools you add or delete here are saved on this device only.
To share them with everyone: Download tools.json, then upload that file to GitHub replacing the old one. Never edit index.html to add tools.
